##### 什么是AI Agent
- AI Agent 是一种能够自主感知环境、做决策，并调用工具完成任务的智能系统
##### Agent类型
- **ReAct**：Reasoning + Acting，推理 + 行动交替进行，每一步都是：先想，再做，看结果，再想，再做
	- 适合探索性任务
- **Plan & Execute**：先整体规划，再逐步执行
	- 适合结构化任务
##### RAG vs Agent区别
- **RAG**：用户问题 → 检索文档 → 塞进Prompt → 模型回答
- **Agent**：用户问题 → 模型自己决定 → 调用工具/搜索/执行代码 → 回答
##### Function Calling vs MCP
- **Function Calling**：模型可以调用外部工具的能力
- **MCP（Model Context Protocol）**：是一种标准协议，用于统一大模型访问外部工具、数据源和服务的方式，提供标准化工具接口
##### MCP vs Skill区别
- MCP：工具接入的标准协议
- Skill：为完成某类任务封装好的能力模块
##### Agentic search
是一种由 AI Agent 主导的搜索方式，它能够自主规划、多步检索、调用工具，并逐步优化结果，而不是一次性返回答案
- Agentic Search的核心能力：
	1. 任务拆解
	2. 多步检索
	3. 工具调用
	4. 结果评估
	5. 信息整合
