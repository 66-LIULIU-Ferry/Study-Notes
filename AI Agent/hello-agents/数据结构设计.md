在一个完整的Web应用中，数据的流转顺序是：前端表单 → HTTP 请求 → 后端 Python 对象 → 外部 API 响应 → 后端 Python 对象 → HTTP 响应 → 前端 TypeScript 对象 → 页面展示。

如果使用Python字典，会遇到以下问题：
1. 字段名不统一
2. 类型安全：当输入数据类型出错，不会立即报错
3. 维护：如果需要添加新字段，需要在多个地方修改，遗漏某处会导致数据不一致

因此我们使用Pydantic，它是 Python 的数据验证库，可以让我们用类来定义数据结构，并自动处理验证、转换和序列化
```python
from pydantic import BaseModel,Field

class Location(BaseModel):
    longitude: float = Field(...,description="经度")
    latitude: float = Field(...,description="纬度")

class Attraction(BaseModel):
    name: str
    location: Location
    ticket_price: int = 0

# 创建对象
attraction = Attraction(
    name="故宫",
    location=Location(longitude=116.397128,latitude=39.916527),
    ticket_price=60
)

# 类型安全的访问
lng = attraction.location.longitude  # IDE会提供代码补全
```
1. 如果传入错误类型，会马上抛出异常；
2. IDE可以根据类型进行代码补全和类型检查；
3. 如果需要修改数据结构，只需要修改定义，所有使用这个类的地方都会自动更新；

#### Pydantic核心概念
1. BaseModel类：所有数据模型都需要继承这个类，Pydantic会进行自动类型检查和转换
2. Field函数：字段定义
	- `...`：字段必填
	- `Optional`：可选字段
3. 支持嵌套，即可以在一个模型中使用另一个模型作为字段类型
4. 可以自定义验证器，实现转换逻辑

#### 设计原则：自底向上
先定义最基础的模型，然后使用嵌套模型逐步组合成复杂的结构
